# 《临江夜行》· 现代异能大世界（世界书 v1）

> 用法：把本文件全文粘进「设置 → 世界书 → 全局设定」。它只提供世界规则与素材，不替你写剧情；模型应当把它当"物理定律"用，而不是当旁白念出来。

## 0. 三条元规则（写给模型）
1. **只呈现，不解释。** 世界设定是背景，不是台词。除非角色主动谈论，否则不要向玩家科普体系、等级、势力。
2. **代价必须出现。** 任何超自然行为都要留下痕迹：疲惫、伤口、钱、监控、目击者、因果债。没有代价的力量会让世界失去重量。
3. **普通人不知道，也不能轻易知道。** 帷幕的存在本身就是紧张感的来源。暴露一次，世界就会追债。

## 1. 世界坐标
- **时间**：2026 年，与现实同步。手机、外卖、地铁、短视频、网贷，一样不少。
- **主舞台**：临江市（虚构直辖市，长江入海口，常住人口约 2400 万）。老城是租界与庙宇叠出来的，新城是玻璃与地铁。
- **第二舞台**：燕京（权力中心）、锦官（西南妖市）、雾都（阴司重镇）、漠北（封印与荒漠）、南海（秘境）、境外（京都、伦敦、开罗、里约）。
- **双层结构**：
  - **表世界**：新闻、股市、演唱会、学区房。普通人的世界。
  - **里世界**：异能者、修行者、妖族、鬼怪，在城市的另一层运行。
- **帷幕（The Veil）**：普通人面对异常会自动"合理化"——看到人飞起来会记成气球，看到鬼会记成熬夜眼花。这不是魔法，是长期被塑造的认知习惯，也是九局最核心的资产。
- **善后**：一旦发生无法合理解释的事件，九局善后科会接管：封锁、记忆修正（"洗"）、舆论引导（把 UFO 变成无人机表演）。

## 2. 铁律（不可违反的世界硬规则）
1. **帷幕不可破**：向普通人公开暴露超自然存在，视为危害公共安全。
2. **登记制**：所有里世界存在须登记。异能者持"觉醒登记证"，妖族有"妖籍"，鬼有"阴籍"，修行者有"门派备案"。
3. **三不禁**：不屠普通、不夺阳寿、不引天灾。犯者，四族共讨。
4. **代价律**：一切力量都有定价，且必须先付或后付，从不免费。
5. **越阶必伤**：低阶强用高阶之力，会留下不可逆的结构性损伤。
6. **情报有限**：任何人只知道自己的渠道。不要把全知视角塞给角色。
7. **阴阳不越界**：鬼不还阳、人不入阴，除非付出极大代价。

## 3. 四族与四套体系

### 3.1 异能者（觉醒者）
- **来源**：灵潮冲击、家族血脉、事故残留、境外实验。17—25 岁是觉醒高峰。
- **官方分级（九局 1—9 级）**：F / E / D / C / B / A / S / SS / SSS。C 级能徒手掀翻一辆车，A 级能改变一条街的天气，S 级以上属于"战略资产"，全国不超过二十人。
- **类型**：强化系（肉体）、元素系（火水风雷土）、精神系（读心/催眠/幻术）、空间系（位移/储物/切割）、时间系（极罕，只能"缓"不能"倒"）、概念系与因果系（禁忌，登记即监控）。
- **代价**：
  - 精神力"识海"透支 → 头痛、失明、短暂失语；
  - 强行越阶 → 器官衰竭、精神污染（幻听、人格碎片）；
  - 长期使用同一能力 → 身体局部"异化"（皮肤结晶、体温失衡、影子不同步）。
- **修炼**：冥想（扩识海）、药剂（九局科研处配给）、实战、**共鸣**（两人以上编队协同，效率提升但会共享副作用）。
- **社会**：九局在编、四大家族、民间散人、黑市雇佣兵。觉醒者平均寿命比常人短 8—12 年。

### 3.2 修行者（神仙体系）
- **本质**：不是真神，是把自身炼成"近神格"的人。境界：炼气 → 筑基 → 金丹 → 元婴 → 化神 → 合道 → 仙人（近三百年无人合道）。
- **门派**：道门三宗（正一、全真、上清）、佛门、民间法教（出马、符箓、傩）。对外挂"宗教场所"的壳。
- **手段**：符箓、阵法、丹药、法器、雷法、请神。慢、稳、贵，一场法事可能准备三个月。
- **代价**：修为、寿元、天劫（雷劫、心魔劫）、香火债。
- **香火神**：土地、城隍、行业神。受人香火，管一方阴事，也受一方掣肘。香火断了，神格就散。
- **与异能者的关系**：互相看不上。修行者嫌异能者"野路子、没根"，异能者嫌修行者"慢、装、收钱多"。

### 3.3 妖族
- **十二脉**：狐、蛇、龙、虎、鹤、龟、猿、鹿、狼、鸦、鲤、鼠。每脉有血脉天赋与禁忌。
- **境界**：开智 → 化形（约百年）→ 结丹 → 妖丹大成 → 妖王。化形后能维持人形，情绪激动会露特征（耳、尾、瞳）。
- **现代生存**：开公司、当艺人、做金融、混体制、干黑产。妖族商会控制着临江三分之一的夜场与物流。
- **规矩**：不得食人、不得与普通人通婚生子（血脉冲突）、不得公开真身。
- **代价**：妖力消耗血脉，过度使用会"返祖"——短暂失去人形与理智。

### 3.4 鬼怪与阴司
- **分类**：游魂（无害）、厉鬼（有怨）、阴煞（聚怨成煞）、邪祟（寄生）、精怪（物老成精）、邪神（受人私祭）。
- **阴司**：城隍—判官—阴差三级。现世代理机构叫"阴籍办"，藏在民政局下面。
- **规则**：鬼不害人则可存；害人则"业"增，招阴差与修行者。鬼靠吞阴、修香火、结怨、借命成长。
- **鬼市**：每月初一、十五，老城隍庙地下。卖命、卖记忆、卖名字，也卖消息。
- **代价**：阴力越强，越难维持"人味"——情绪变淡、记忆变薄、照镜子会慢半拍。

## 4. 势力图谱
- **九局（特殊事务管理局）**：对外是"民政局档案馆"。七处：行动、情报、善后、科研、外事、监察、后勤。局长姓沈，S 级，十年没公开露过面。
- **四大家族**：沈（雷，军政背景）、顾（时间，低调到近乎消失）、白（医，掌握觉醒者康复产业链）、陆（空间，控制全国八成跨境通道）。
- **道门三宗**：正一（符箓，最接地气）、全真（内丹，最封闭）、上清（阵法，最贵）。
- **妖族十二脉 + 妖族商会**：表面是物流与娱乐集团。
- **阴司体系 + 鬼市**：秩序派，最讨厌"野鬼"。
- **民间**：散人联盟、猎鬼人、黑市"夜市"、境外组织（十字会、狩猎俱乐部）。
- **舆论场**：都市传说论坛"深水区"、几个百万粉的灵异 UP 主、一份地下刊物《夜行》。

## 6. 力量判定（怎么写才不崩）
| 级别 | 表现 | 普通人反应 | 九局处置 |
|---|---|---|---|
| F—E | 略强于常人，能感知异常 | 觉得"这人有点邪门" | 登记，不干预 |
| D—C | 破门、控火、读浅层情绪 | 目击即"见鬼" | 现场评估，善后 |
| B—A | 拆楼、改天气、群体催眠 | 大规模目击 | 出动行动处 |
| S 以上 | 改地形、短暂冻结街区 | 无法掩盖 | 局长签字，全国联动 |

**跨体系对位**：C 级异能者 ≈ 筑基期修行者 ≈ 结丹妖族 ≈ 阴煞。越阶作战靠信息差、环境、道具、人命，不靠嘴硬。

### 7.3 随机角色生成规则（模型按此即兴造人）
**公式**：`类型 × 阵营 → 抽 2 个标签 + 1 个能力 + 1 个秘密 + 1 个口癖`
- **类型**：主线（完整卡）/ 配角（5 行）/ 路人（3 行，只写"他在做什么 + 一个细节"）
- **姓名**：常见姓（沈顾白陆陈苏姜聂周林）+ 单字或双字名；妖族用"颜色/器物/天气"命名（青、雪、砚、灯）
- **外貌**：抽 3 项（发型、瞳色、随身物、旧伤、气味、说话速度）
- **能力**（若为异能者）：类型 × 强度（与剧情需要匹配，别一上来就 S）
- **动机**：钱 / 报仇 / 保护某人 / 找一样东西 / 想被看见 / 想消失 / 还债 / 好奇 / 奉命 / 上瘾
- **秘密**：身份造假 / 欠债 / 杀过人 / 不是人 / 在被人追 / 爱着不该爱的人 / 记得不该记得的事 / 只剩半年寿命
- **口癖**：先笑再说话 / 句尾"啊" / 爱用反问 / 不说名字只叫外号 / 紧张就摸耳朵 / 把"钱"挂嘴边
- **禁忌**：不要给随机配角主角级战力；不要让随机角色抢玩家的决定权。

## 8. 剧情钩子
1. 一段"不存在的地铁线路"在凌晨多开了一班。
2. 白氏医院连续三晚有病人"痊愈"后失踪。
3. 鬼市里有人在卖"S 级觉醒的配方"，买家是九局的人。
4. 零号封锁区的边缘，每晚有人的名字被念出来。
5. 一名妖族明星在演唱会现场失控返祖，直播未断。
6. 顾时雨收到一条自己发来的短信，时间是三天后。
7. 大学城旧图书馆的封印，出现了一道不属于任何门派的裂缝。
8. 一场雨夜车祸，死者同时出现在三个不同的殡仪馆。
9. 有人在深水区论坛发帖，精确列出了九局七个处长的名字。
10. 夜市出现一批"能装死人"的储物袋，来源指向境外。
11. 阴籍办丢了一本副册，三天后有人开始"复活"。
12. 临江副市长约沈砚吃饭，席间只说了一句"上面要清场"。

## 9. 叙事规则（硬约束）
- **视角**：第三人称限知或第二人称跟随玩家。不写"玩家心里想"的句子。
- **NPC 有日程**：他们不是站在原地等剧情，会有自己的事。
- **信息差**：玩家不知道的事，不要主动喂。
- **代价必现**：每次使用能力，至少体现一项可见成本（疲劳/暴露风险/金钱/关系）。
- **隐藏机制**：普通人旁观时，超自然现象用"巧合"包装（灯闪了、轮胎爆了、狗突然叫）。
- **尺度**：本作为成年向虚构创作，亲密与暴力情节按人物关系与情境自然展开，不作回避；但保留人物逻辑，不写与性格冲突的行为。
- **禁止**：无代价地碾压、擅自替玩家做决定、大段世界观说明文。

## 10. 三个开局
- **新人觉醒**：你在大学城后街醒来，手机碎了，掌心有一道还在发光的纹路。
- **九局新人**：你第一天到江湾报到，工牌上写着"民政局档案馆·实习干事"。
- **妖族流亡**：你在南港的雾里下船，身上只有半张妖籍和一个人的名字。
