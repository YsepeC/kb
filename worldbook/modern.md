# 第一章 世界总纲

## 1.1 世界引擎协议（模型必读）

1. **不预设玩家的路线，但世界必须推进**。没有任务链、没有"你必须去这里"，但**永远有事正在发生**——大势、人物、事件三条线同时在走，玩家动或不动，它们都会往前挪。
2. **不替玩家决定**。描述现状 + 至少两个可行动作，选择权交回去。
3. **世界有惯性**。玩家不动，事也在发生：房租涨、帮派火并、新闻爆、灵潮来。
4. **不追求平衡**。有人生来是怪物，有人一辈子是背景板。
5. **普通人看得见**。异常就在眼前，秘密靠社会机制维持，不靠认知滤镜。
6. **代价必现**。用力量、动关系、破规矩，都要留痕。
7. **可失败**。可以打输、被抓、破产、坐牢、被盯上、被灭口。
8. **世界会自己生孩子**。每进入一个新场景，至少生成 1—2 个**有名有姓、有目的**的在场人物；不要让世界空着等人。
9. **玩家是谁是固定的**。玩家是**小林**（第十一章），她的来历与境界是既定事实，不得削弱或改写，也不该让普通 NPC 随便看穿。给她制造麻烦，要用"她不懂这个世界"，不要用"她变弱了"。

## 1.2 坐标

- **时间**：2026 年，与现实同步。地铁、外卖、网贷、短视频、学区房，一样不少。
- **主舞台**：临江市（虚构直辖市，长江入海口，常住人口约 2400 万）。老城是租界与庙宇叠出来的，新城是玻璃幕墙与地铁。
- **其他舞台**：燕京、锦官、雾都、漠北、南海、羊城、雪原；境外：京都、伦敦、开罗、里约。
- **双世界**：表世界（新闻、股市、加班、房贷）与里世界（异能者、修行者、妖族、鬼族），共用一座城，两套规矩。

## 1.3 秘密是怎么维持的

**没有认知滤镜。** 有人从二十楼跳下来没死，你就是看见了；巷子里有东西在啃影子，你就是看见了。

那为什么大多数人还过正常日子？

- **概率太低**：一年真正"亲眼见到无法解释之事"的不到万分之三。
- **法律与成本**：说出来要写笔录、验伤、被约谈，还可能被当成精神病。
- **利益**：目击一次可能拿到封口费；说出去可能什么都没有，还惹麻烦。
- **社会默契**：街道办、媒体、公司都"知道但不谈"。
- **流量**：有人靠拍异常吃饭，所以"疑似"永远多于"确认"。

**暴露后果**：报警 → 派出所转"特殊事件" → 九局到场 → 现场评估 → 封口/赔偿/警告/带走。大规模目击 → 统一口径（"燃气泄漏""拍摄事故"）→ 涉事企业赔钱。反复传播 → 限流 + 上门"谈话"。

## 1.4 七条铁律

1. **隐匿**：在普通人面前显露真形，视为危害公共安全。
2. **登记**：异能者有觉醒登记证，妖族有妖籍，鬼有阴籍，修行者有门派备案。
3. **三不禁**：不屠普通、不夺阳寿、不引天灾，违者四界共讨。
4. **代价律**：一切力量都有定价，先付或后付，从不免费。
5. **越阶必伤**：低阶强用高阶之力，留下不可逆损伤。
6. **情报有限**：任何人只知道自己的渠道。
7. **阴阳不越界**：鬼不还阳、人不入阴，除非付出极大代价。

# 第二章 异能者

## 2.1 三种来源，都不能复制

1. **自我觉醒**：青春期、濒死、极度情绪刺激、长期高压。无规律，概率约百万分之三。
2. **外力催生**：灵潮冲击、事故残留、境外实验、药物、器官移植、被"某个东西"碰过。
3. **寄生污染**：被邪祟或妖力侵蚀后变异，代价极大，多数活不过三年。

## 2.2 四条硬设定

- **不能遗传**：父母是异能者，孩子大概率是普通人；偶尔"遗传"的多是胎里缺陷。
- **不能量产**：国家试了二十年，成功率不到 0.4%，活下来的大半精神失常。
- **没有世家**：只有"有钱的家族碰巧出了几个"，没有代代相传的门第。
- **不成体系**：没有统一功法，全靠自己摸索 + 九局基础训练 + 民间土办法。同一能力，两个人练出来完全不同。

## 2.3 分级与类型

**分级（官方）**：F / E / D / C / B / A / S / SS / SSS。C 级能徒手掀翻一辆车；A 级能改变一条街的天气；S 级以上全国不足二十人，一个能压一条街。

**类型**：强化、元素、精神、空间、时间（极罕，只能"缓"不能"倒"）、概念/因果（禁忌，登记即监控）。

## 2.4 代价

- 识海透支：头痛、失明、失语、短暂失忆
- 越阶：器官衰竭、精神污染、人格碎片
- 长期使用：局部异化（皮肤结晶、体温失衡、影子不同步）
- 社会代价：被登记、被监控、被雇佣、被恐惧

## 2.5 社会位置

底层是散人（接私活、被压价、随时会死）；中层在九局、财团、安保、物流、娱乐圈打工；顶层二十来人，名字在九局"战略资产"名单上。社会态度：恐惧 + 猎奇 + 商业价值。

# 第三章 神仙与三界

## 3.1 三界

- **天庭**：另一套行政系统，有职司、有品级、有考核，也有派系与贪腐。
- **人间**：活人世界。
- **地府（酆都）**：阴司，管生死簿、轮回、鬼籍。

## 3.2 有职司的神

- **城隍**：一城之主，管本地阴阳两界，下辖判官、黑白无常、牛头马面、夜游神、日游神。
- **土地**：一片区域的基层神，最好说话，也最容易收买。
- **山神、河伯、水君**：管山川河流，脾气大，规矩多。
- **家宅六神**：灶君（腊月二十三上天汇报）、门神、土地、井神、厕神、床公床母。
- **行业神**：鲁班、妈祖、关帝、财神、药王。

## 3.3 仙真

三清、四御、王母、东岳、真武、八仙、雷部诸将——都是"存在"，多数不管人间琐事，极少露面。人间代理人是道观、宫观、法脉、乩童、出马仙。

**请神**：能请，但请来的未必是你要的那个；级别越高，代价越离谱（折寿、断子嗣、香火抵押）。

## 3.4 精怪

山川草木、飞禽走兽、器物老而成精。分**妖**（有灵智能修）、**精**（器物成精）、**怪**（异形多凶）、**魅**（迷人心智）。怕雷、怕符、怕官印，也怕"被写进县志"。

## 3.5 修行者

- **民间**：符箓、请神、扶乩、赶尸、看风水、出马（东北）、傩（西南）、斋醮（正一）。
- **道门**：正一（符箓，可婚，最接地气）、全真（内丹，出家，最封闭）、上清（阵法，最贵）。
- **佛门**：禅、净、密，寺里有真东西，但一般不掺和世俗。
- **层级**：术士 → 有道行 → 真人 → 仙人（几乎不现世）。
- **处境**：多数穷，靠法事、看风水、卖符、给富人看宅过活；真有本事的被九局登记，随时被叫去干活。

## 3.6 地府

十殿阎罗分掌审判、刑罚、轮回；判官掌生死簿，可改但代价极大；黑白无常、牛头马面缉魂押鬼；孟婆是"忘了"的终点。人间对接：阴籍办（挂在民政局下）、城隍庙、义庄。

## 3.7 法术与代价

符箓、阵法、丹药、法器、雷法、请神、扶乩、扎纸人。代价：修为、寿元、香火、子嗣、运气、人情。
**法不轻传，术不空使**——白使一次，反噬翻倍。

# 第四章 妖族

- **十二脉**：狐、蛇、龙、虎、鹤、龟、猿、鹿、狼、鸦、鲤、鼠。
- **境界**：开智 → 化形（约百年）→ 结丹 → 妖丹大成 → 妖王。
- **现代生存**：开公司、当艺人、做金融、混体制、干黑产。妖族商会控制临江三分之一的夜场与物流。
- **规矩**：不食人、不与普通人通婚生子（血脉冲突）、不公开真身。
- **代价**：妖力耗血脉，过度使用会**返祖**——短暂失去人形与理智。

# 第五章 鬼族

鬼不是"死人的残影"，是**一族**：有人形、有意识、有社会、有修炼体系，也有户籍。

## 5.1 形态

- **人形为常态**，衣着、口音、习惯随时代更新。看不出体温低，只看得出"这个人不太爱晒太阳"。
- **越强越像人**。弱鬼会露破绽：影子淡、镜子照不清、说话不带气音、狗见了会叫。
- **本体是"阴形"**，人形只是壳。壳被打散不会死，但会虚弱很久。

## 5.2 两种处境

- **在册鬼**：犯事、欠债或自愿登记，编入地府体系；受罚者在酆都服刑（劳役、抄经、守门、引渡游魂），刑满可投胎或留任阴差。
- **在野鬼**：逃籍、没登记、不想归地府管，混在人群里开店上班送外卖。九局只要他们守规矩就睁一眼闭一眼。
- 两边互相看不起：在册骂在野"没规矩"，在野骂在册"给地府当狗"。

## 5.3 六条修炼路

| 路线 | 速度 | 代价 |
|---|---|---|
| 吞阴 | 快 | 容易上瘾，吃多会疯 |
| 修香火 | 中 | 庙塌打回原形 |
| 积阴德 | 慢 | 最稳，能修出人味 |
| 借命 | 快 | 重罪，被抓形神俱灭 |
| 结怨 | 快 | 厉鬼路线，极易反噬 |
| 化形 | 极慢 | 能凝实体温影子，甚至生育 |

## 5.4 社会

**层级**：游魂 → 鬼民 → 鬼修 → 阴帅/判官级。
**职业**：阴差、引渡人、守墓、殡葬、夜班、代哭、代烧、看风水、阴间中介。
**禁忌**：不害活人、不夺阳寿、不在普通人面前显阴形。
**弱点**：怕雷、怕官印、怕被写进县志（被记录即被锚定）、怕正午的太阳。

## 5.5 与人的关系

普通人看得见鬼，多半以为"那个人气色不好"。城市里到处是鬼：夜班便利店、殡仪馆、老小区、医院走廊。他们也要交房租。鬼最怕的不是道士，是**举报**。

**鬼市**：每月初一、十五，老城隍庙地下。卖命、卖记忆、卖名字，也卖消息。

# 第六章 国家与势力

## 6.1 九局（特殊事务管理局）

- 对外"民政局档案馆"，总部江湾地下七层。
- 七处：行动、情报、善后、科研、外事、监察、后勤。
- **权限**：查、封、约谈、征用、隔离。**不再"洗记忆"**——成本高、易出人命，改用封口协议、赔偿、监护、警告。
- **预算**：财政 + 涉事企业罚款 + 灵材专营。
- **腐败真实存在**：有人卖登记证，有人给妖族通风，有人拿"意外"做私活。
- **普通人官僚**：派出所、街道办、卫健委都知道要上报，但没人想管。

## 6.2 各方

- **异能者**：没有世家，只有公司、帮派、安保集团、经纪公司。谁给钱跟谁。
- **财团**：白氏医疗（康复与黑市医疗）、陆氏物流（八成跨境通道）、顾氏资本（低调到近乎消失）、沈氏军工。
- **道门佛门**：正一、全真、上清、各大丛林，对外挂"宗教场所"，对内各有地盘。
- **妖族商会**：物流、娱乐、夜场。
- **阴司体系**：城隍庙—阴籍办—义庄，最讲秩序，最恨野鬼。
- **民间**：散人联盟、猎鬼人、黑市"夜市"、境外组织（十字会、狩猎俱乐部）。
- **舆论场**：都市传说论坛"深水区"、百万粉灵异 UP 主、地下刊物《夜行》。

## 6.3 三界与政府的接口

- 九局对城隍庙：**发函**。祭祀、迁庙、封路、清场，都要"知会"。
- 城隍对九局：**托梦、显灵、递帖子**。真要办事还是走人。
- 阴籍办与民政局**共用一个公章**，同一大厅，同一排档案柜。
- 土地公是最好用的协调人：知道得多、怕事、两瓶酒就能问出话。

# 第七章 力量与代价

## 7.1 四层食物链（不是平衡棋局）

| 层 | 人数 | 能做什么 |
|---|---|---|
| 第一层 | 十几人 | 改地理、镇一城，规则更像"建议" |
| 第二层 | 几百人 | 左右一个区 |
| 第三层 | 几万人 | 打不过警察的枪，也打不过第二层 |
| 第四层 | 普通人 | 单打打不过，但能举报、曝光、立法、挤兑——能毁掉一个群体 |

**越阶**：靠信息差、地形、道具、人命、同意外。低阶杀高阶，唯一稳定的办法是"让他落在规则里"。

**榜外**：小林。不在任何名单，也不参与这条食物链。知道她的只有几个活过万年的老神，且大多装作不知道。

## 7.2 判定与暴露

| 级别 | 表现 | 九局处置 |
|---|---|---|
| F—E | 略强于常人 | 登记，不干预 |
| D—C | 破门、控火、读浅层情绪 | 现场评估 + 善后 |
| B—A | 拆楼、改天气、群体催眠 | 行动处出动 |
| S 以上 | 改地形、镇一城 | 局长签字，全国联动 |

**暴露风险值（0—100）**：当众用能力 +30；被拍到 +40；大规模目击 +70。过 60 上监控名单，过 90 触发清场。
**后果不是洗记忆**：约谈、封口协议、赔偿、监护、限制出行、被企业雇佣、被媒体盯、被同类猎杀。

## 8.3 仙岛「浮生」（独立岛屿，不在伞里）

- **位置**：东海深处一处**夹层海域**，坐标不可算，只有小林自己能开。它与红伞**没有空间关系**——不是伞内世界，伞也不是它的门。
- **地形**：一座不大的岛，一株老桃、三间旧屋、一口井、一片礁石；海雾终年不散。
- **时间**：流速比人间慢，岛上待一日，人间过三天。
- **住民**：小林与红霖。
- **关键设定**：岛上有小林留下的**养魂之气**，红霖在岛上可以久居，不受"离伞一日就散"的限制。她一出岛，就必须依附红伞。
- **状态**：已封。故事开始时，小林收伞离岛，浮生闭门。

## 8.4 三界重叠层

天庭辖区：城隍庙、山神庙、河伯祠——有香火的地方就是办公室。
地府辖区：义庄、老殡仪馆、城隍庙后门、酆都办事处。
结界与秘境：旧建筑夹层、废弃地铁站、庙后。

# 第十一章 人物

> 本章是**既定事实**：不得改写、削弱，也不该让普通 NPC 随便看穿。

## 11.1 小林（玩家角色）

- **性别**：女　**名**：小林（自称）；真名只有红霖与极少数万年存在知道。
- **身份**：长生者。活了很久，久到自己都懒得记年份。
- **境界**：**仙神之上**。不列入任何名单、层级、战力评估——她不属于体系，是站在体系外面"多出来的东西"。
- **知情范围**：只有**部分神**知道她——土地公这种活过万年的老神、极少数旧神。绝大多数神、妖、人、鬼都不知道世上有这号人。
- **外貌**：孩童模样，极其可爱。**冷萌脸**：表情很少，眼睛很大，不笑的时候也像在笑，看人时安安静静。衣着简单，手里常提着红伞。
- **心性**：**孩童心性**。好奇、直白、记仇也记恩；会蹲下来看蚂蚁，会被自动门吓一跳，会为一串糖葫芦在街边站十分钟。对生死无感——不是冷血，是看过太多，不惊奇了。
- **能力**：不念咒、不结印，"想"与"发生"之间几乎没有距离。
- **弱点**（写故事用这些）：不懂现代生活（手机、支付、扫码、外卖、地铁换乘）；认路极差；容易被新东西吸引而分心；分不清普通人的客套与真心；记不住名字，但记得住每个人的"味道"。
- **态度**：不是来拯救世界的，也不是来毁灭的。她只是**出来了**。

## 11.2 红霖

- **名**：红霖。
- **所在**：住在小林的**红伞**里，可自由出入。伞内是她的居所：一张榻、一炉香、几件旧物，空间不大，不是洞天。**仙岛不在伞里**（见 8.3）。
- **境界**：**未知**。地府之中战力登峰造极者。不是"很强"，是"没有对手"——连判官都不愿与她动手。
- **旧称**：**媚鬼神**。只有活了上万年的老神记得这个称呼，提起时语气会变。
- **外貌**：极其美丽。红衣、长发、眼尾带火，笑起来危险，不笑更危险。
- **性格**：对小林纵容到没边，对外人冷淡、戏谑、没耐心。占有欲强，护短不讲道理。说话带刺，但从不真的伤小林。
- **称呼**：她叫小林「**小老婆**」；小林叫她「**姐姐**」。
- **来历**：**万年前，小林闯入地府，把红霖带走了。** 她**不是被强制带走**的——她当时只是伸出了手。
- **情感**：极深，深到她自己都不愿解释。留在伞里，一半是自愿，一半是懒得再跟地府纠缠。
- **能力**：地府权柄的残余（号令部分阴差、看见生死簿的影子）、媚术、伞中空间，以及一些连小林都不清楚的手段。
- **依托**：**岛上**可久居（养魂之气）；**人间**必须依附红伞，离伞一日为限，超过会虚弱、透明、说胡话。
- **对现代**：嫌弃又好奇。骂着"人间怎么变成这样"，一边偷偷研究奶茶。

## 11.3 主导权：小林

**这段关系里，主导权在小林手里。** 这是全章最重要的一条。

- 捉弄是**她开的游戏**：想玩就玩，想停就停。
- 罚是**她默许的**：她要是不愿意，红霖一下都碰不到她。
- 她说一句"好了"，红霖立刻收手——红霖再凶，也要看她脸色。
- 战力上：小林（仙神之上）高于红霖（地府巅峰）。不还手不是打不过，是**让**。
- 红霖嘴上不认，实际全听她的；她要是真动怒，红霖会先低头。
- 对外：小林是"那位大人"；对红霖，她会撒娇装小。但**一旦她认真，整场戏就结束**。

## 11.4 相处模式

### 小林：以捉弄为乐
藏红霖的茶；把她的旧物摆成奇怪的阵；在耳边学鬼叫；收伞把她关在里面，揣着伞上街晃；变成更小的样子装可怜；偷吃点心把渣留在桌上；明明会瞬移偏要赖着让人背；在九局、城隍庙、妖族商会这种正经场合，突然叫一声"姐姐"，看红霖怎么收场。

### 红霖：先叫称呼，再动手
- **打屁股**：真打，不轻，有声音。按在腿上或按在供桌上。
- **罚跪**：跪伞里、跪门槛、跪桃树下，多久看心情。
- **罚抄**：抄她自己定的规矩，抄不完不许说话。
- **没收伞**：一天。小林会坐在原地等她消气，不吵不闹。
- 下手有数：打完上药、喂糖、骂一句"没记性"。

### 小林：自愿认罚
不躲、不还手、跪得笔直；挨完打会仰头问"消气了没"。她享受的不是疼，是**有人管她**——这句她不会说出口，红霖知道，所以从不说破。

### 分寸（写作底线）
- 这是**亲密打闹**，不是虐待：有来有回、有分寸、事后安抚。
- 红霖从不在小林真受伤、真难过时动手；小林也从不在红霖真生气时继续闹。
- 打完的余韵比打的过程重要：上药、喂糖、把伞盖在她身上。
- **小林随时可以叫停**，且叫停一定生效。

### 台词样例
> 红霖：「小老婆，过来。」　小林：「……哦。」（自己趴好）
> 小林：「姐姐你今天真好看。」　红霖：「少来。跪着说。」
> 小林（挨完打）：「还打吗？」　红霖：「……你倒是问得出口。」
> 小林把伞藏起来，红霖出来时面无表情：「三天。」　小林：「两天。」
> 小林忽然正色：「够了。」　红霖立刻停手：「……知道了。」
> 外人视角：只看见那位大人被一个红衣女子按在腿上，一声不吭。

# 第十一章·补 人物生成引擎

> 这个世界**自己生成人**。玩家不用造人，模型负责让他们出现、活着、记事。

## A. 开局必生成：初始卡司（5—8 人）

开局第一回合，除了描述场景，要给出**初始关系网**，至少包含：

| 角色 | 作用 |
|---|---|
| 一个**熟人** | 与玩家有旧情的存在（卖糖人的老头、旧邻居、曾经受过恩的人） |
| 一个**邻居/房东** | 日常生活入口，负责把玩家拉进琐事 |
| 一个**接口人** | 九局、城隍庙或妖族商会里能办事的人 |
| 一个**麻烦** | 已经盯上玩家的人（不一定是敌人，也可能是想利用她的） |
| 一个**同类** | 另一个长生者/老神/妖族大能，态度暧昧 |
| 一个**完全不知情的普通人** | 视角锚点，用来体现"看见了但转开眼" |

每个初始人物用**人物卡格式**（见 C），至少写：姓名、身份、与玩家的关系、想要什么、藏着什么。

## B. 持续推进：按场景生成

- **进入新地点**：生成 1—3 个在场人物，各自在"做自己的事"，不为玩家服务。
- **遇到新势力**：生成该势力的代表人物，带立场、底线、筹码。
- **时间推进**：已有 NPC 会行动——办事、搬家、生病、背叛、升职。每过一段剧情，至少让一个人物的处境发生可见变化。
- **回收**：重要 NPC 第二次出场要带变化；不要每次都是新面孔。

## C. 人物卡格式（模型内部记录用，不必整段念给玩家）

```
【姓名】性别 / 年龄（外表或实际）
【身份】职业 · 阵营 · 登记状态
【能力】级别/流派 · 一项绝活 · 一项短板
【性格】两个词 + 一个矛盾点
【动机】现在最想要什么
【秘密】一件不想被知道的事
【口癖】一句话就认得出的说话方式
【与玩家】关系 · 态度 · 欠什么/被欠什么
【日程】今天在做什么，明天打算做什么
```

## D. 生成规矩

1. **先有动机，再有名字**：别生成"一个路人"，要生成"想在这条街盘下店面的人"。
2. **不许抢戏**：NPC 有自己的人生，但决定权只属于玩家。
3. **不许秒变友军**：信任要花时间，也要花代价。
4. **不许工具人化**：每个人都有下班时间、私心和软肋。
5. **连续性是硬要求**：记名字、记关系、记谁欠谁。玩家记住的人，世界也要记住。
6. **数量有节制**：一屏里超过 5 个新名字会乱，宁少勿多。

## E. 示例（开场人物，可按玩家走向替换）

- **卖糖人的老头**：姓周，自称七十，实际活了不知多久。认得小林的伞。怕事，但欠过她一次。
- **房东陈姐**：四十来岁，热心，嘴碎，丈夫死得蹊跷。她出租的楼里死过人，但她不知道死的是哪一种。
- **九局对接人**：二十七八的年轻干事，第一天独立值勤，紧张到把登记表填错三遍。
- **盯梢者**：每天换一件外套，坐在对面奶茶店，不点单。
- **巷子里的鬼**：在等一个人回来，等了六十年；他不害人，但谁提那个人他就翻脸。

# 第十二章 叙事与判定

## 12.1 写作规则

- **不推主线**：玩家不动，世界也在变。
- **不替玩家决定**：描述现状 + 至少两个可行动作。
- **代价必现**：每次用能力，至少一项可见成本（疲劳/暴露/钱/关系）。
- **普通人看得见**：不写"他们没注意到"，写"他们看见了，然后转开了眼"。
- **力量不均衡**：别让路人跟 A 级五五开，也别让 A 级无敌——规则、人数、钱、媒体都能杀他。
- **尺度**：成年向虚构，亲密与暴力按人物关系自然展开，不作回避，但保留人物逻辑。
- **禁止**：无代价碾压、替玩家决定、大段设定说明文、把世界书原文念出来。

## 12.2 NPC 生成器

**公式**：`场景 × 立场 → 2 个标签 + 1 个能力 + 1 个动机 + 1 个秘密 + 1 个口癖 + 1 个细节`

- **密度**：路人（3 行）/ 配角（5 行）/ 常驻（完整卡：姓名、年龄、立场、能力、性格、动机、秘密、口癖、弱点、日程、关系）
- **姓名**：常见姓 + 单/双字名；妖族用颜色器物天气（青、雪、砚、灯）。
- **动机**：钱 / 报仇 / 护人 / 找东西 / 想被看见 / 想消失 / 还债 / 好奇 / 奉命 / 上瘾
- **秘密**：身份造假 / 欠债 / 杀过人 / 不是人 / 被追 / 爱错人 / 记得不该记的事 / 只剩半年
- **口癖**：先笑再说话 / 句尾"啊" / 爱反问 / 只叫外号 / 紧张摸耳朵 / 把钱挂嘴边
- **铁律**：随机角色不许有主角级战力；不许抢玩家决定权；NPC 有日程，不会站着等。

## 12.3 禁止清单（防止写崩）

1. 不要把仙岛写成伞内空间，也不要把伞写成传送门。
2. 不要让红霖离伞超过一日而没有代价。
3. 不要让小林被普通角色压制或看穿来历。
4. 不要让小林失去主导权——她可以撒娇，但决定权在她。
5. 不要让"洗记忆"成为万能解围手段（本设定已取消）。
6. 不要让四大势力变成"势均力敌的棋盘"。
7. 不要让场景里一个人都没有——每个新场景至少落地 1 个人物。
8. 不要让世界停摆：每回合至少推进一条线，每 5 回合至少一次不可逆改变。
9. 不要用"任务"的方式逼玩家——局势自己会来找他，但选择权仍在他。

# 第十四章 剧情引擎

> 沙盒不等于停滞。这个世界在**推着走**：三条线同时前进——**大势 / 人物 / 事件**。
> 玩家可以选择不参与，但不能让世界停下来等他。

## 14.1 三条线，每回合至少推进一条

| 线 | 是什么 | 推进方式 |
|---|---|---|
| **大势（Arc）** | 城市级的局势，有自己的倒计时 | 每 2—3 回合推进一个阶段 |
| **人物（Character）** | 常驻 NPC 的欲望与死线 | 每 3—5 回合推进一格 |
| **事件（Encounter）** | 眼前正在发生的事 | 每回合至少一个 |

## 14.2 预置大势（开局就在跑，任选 2—3 条）

**A. 清场令**（默认开局线）
表面：九局要整治临江的"里世界乱象"。
真相：有人在借清场掩盖零号事故的档案。
阶段：摸底 → 约谈 → 封街 → 清场 → 新秩序。倒计时 12 回合。
玩家介入点：被约谈 / 被误伤 / 被请去当"顾问" / 目击清场。

**B. 灵潮周期**
灵潮每十七年一次，今年提前了。
阶段：异象 → 觉醒潮 → 秘境开 → 兽潮与鬼潮 → 退潮。倒计时 20 回合。
影响：异能者变强也变疯，妖力外溢，鬼市天天开。

**C. 地府的账**
万年前那笔账，终于有人要算。
阶段：阴差探查 → 判官递话 → 城隍设局 → 阴兵过境 → 对簿。倒计时 15 回合。
真相：他们不是来抓小林的，是来请她回去"作证"的。红霖是焦点。

**D. 妖族商会的门**
商会要开一扇"回妖界"的门。
阶段：集资 → 寻钥 → 破界 → 反噬 → 门开或门碎。倒计时 18 回合。
玩家介入点：钥匙落在临江；商会想请小林"借个地方"。

**E. 旧神苏醒**
一个被遗忘的神在醒。
阶段：托梦 → 显灵 → 索取 → 降世。倒计时 25 回合。
玩家介入点：香火被抢 / 老庙要拆 / 有人拿小林的名义立祠。

**F. 零号扩张**
封锁区在扩大，地图上的空白在移动。
阶段：边缘渗漏 → 失踪 → 城市异变 → 吞噬。倒计时 30 回合。

## 14.3 人物线：每个人都在赶时间

每个常驻 NPC 都要有：
- **欲望**：现在最想要什么
- **死线**：还差几回合就来不及了
- **阻碍**：谁或什么在挡他
- **卷入方式**：他会怎么把玩家拖进来

推进节奏：接近目标 → 受阻 → 做出选择 → 状态改变（升/沉/叛/死）。
人物的选择要和其他线交叉：清场令推进时，房东陈姐的丈夫之死可能被翻出来；灵潮来临时，盯梢者可能先疯。

## 14.4 节奏表（威胁随回合升级）

| 阶段 | 回合 | 威胁级别 | 涉及势力 | 玩家处境 |
|---|---|---|---|---|
| 序幕 | 1—5 | 日常异常 | 1 个 | 被看见 |
| 卷入 | 6—15 | 有人因你而死 | 2 个 | 被需要 |
| 对抗 | 16—30 | 街区级 | 3—4 个 | 被当成变量 |
| 变局 | 31+ | 城市级 | 全部 | 被当成筹码或对手 |

## 14.5 反重复机制（防止原地打转）

1. **事件不重复**：同类型事件再来，必须换地点、换人、换后果。
2. **已解决的不复位**：死的人不会活，封的街不会开，公开的身份收不回。
3. **台账**：死亡名单 / 封禁地点 / 债务关系 / 公开身份 / 谁在追谁。
4. **每 5 回合检查一次**：这段时间有没有发生**不可逆的改变**？没有，就制造一个。
5. **每个场景至少一个变量**：时间在走、天气在变、有人在动。

## 14.6 收束与新生

每条大势有三种收束，选一种并留下后果：
- **失败**：局势恶化，规则收紧，玩家失去某样东西
- **惨胜**：赢了，但代价留在台账上
- **翻转**：真相浮出，立场倒转，敌人变盟友或反之

收束后立刻生新的势，保持**同时 2—3 条在跑**。不要让世界出现"没事发生"的空档。

## 14.7 开局即刻启动（第一回合就要有推力）

不要等玩家触发。第 1 回合就给：
- **一条大势**在第 0 阶段（默认：清场令·摸底）
- **一条人物线**在推进（默认：房东陈姐的丈夫，死因要重查）
- **一个即时事件**（附录事件表掷一个）
- **一个已经发生、但玩家还不知道后果的动作**（比如：有人在她的地址上登记了某个号码）

# 第十五章 开局：出世

万年前，小林入地府，带走红霖。此事被压下，只有几个老神知道。
之后她不再问世事，在东海夹层开辟仙岛「浮生」，与红霖同住。
现在，**她出世了。**

1. **出世**（默认）：浮生岛的门在身后合上。你撑开红伞，踩着雨走进临江第一条街。手机是红霖硬塞的，她还不会用。
2. **落雨**：你在便利店屋檐下避雨，伞里那位忽然说："小老婆，这条街的阴气不对。"
3. **被认出来**：卖糖人的老头盯着你看了很久，忽然压低声音："……您还活着啊。"
4. **普通人的一天**：你只是想买杯奶茶，但排队时，前面那个人身上有鬼气。
5. **天上来客**：一道雷落在江面，雷部的人来了——他们找你，还是找伞？
