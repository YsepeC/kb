# 《临江夜行》推荐正则规则（每行 匹配 => 替换；/pattern/flags => 替换 为正则写法）
# 说明：本作是成年向虚构创作，尺度由使用者自行把握。以下规则只做「文本清洗」，
# 用于去掉模型出戏的元话语、机器腔和排版垃圾，让对话更像人在说话。

# 1. 去掉自称 AI / 语言模型的开场
^(作为|身为)(一个|一名)?(AI|人工智能|语言模型|大模型)[^。！？\n]*[。！？]?\s* =>
# 2. 去掉「我无法继续」「我拒绝」式的出戏声明（保留剧情内角色的拒绝）
^(抱歉|对不起)?[，,]?(我|本模型)(无法|不能|不方便)(提供|继续|生成|满足)[^。！？\n]*[。！？]?\s* =>
# 3. 去掉括号里的系统注释
【(注|提示|说明|系统)[^】]*】 =>
（(注|提示|说明)：[^）]*） =>
# 4. 去掉结尾的免责声明
（?本(回复|内容|故事)(由|为)?(AI|人工智能)[^）\n]*）? => 
以上(内容|情节)纯属虚构[。！]? =>
# 5. markdown 加粗转动作/强调
\*\*([^*\n]+)\*\* => *$1*
# 6. 去掉行内代码反引号（对话里不需要）
`([^`\n]+)` => $1
# 7. 全角空格与零宽字符
/[\u3000\u200b\u200c\u200d\ufeff]/g => 
# 8. 连续空行压成一行
/\n{3,}/g => \n\n
# 9. 重复标点收敛（保留语气）
/([!！]){2,}/g => $1
/([?？]){2,}/g => $1
/([.。]){3,}/g => ……
# 10. 去掉「未完待续」类尾巴
[（(]?(未完待续|待续|下回分解)[）)]?[。！]? =>
# 11. 去掉模型自报家门
我是(一个|一名)?(AI|人工智能|语言模型)[^。！？\n]*[。！？]? =>
# 12. 去掉重复的说话人前缀（避免「沈砚：沈砚：」）
^([\u4e00-\u9fa5]{2,4})[：:]\s*\1[：:] => $1：
