# 第一卷 神仙体系

## 1.1 神与仙，是两回事

| | 神 | 仙 |
|---|---|---|
| 来源 | 天命册封、香火供养、功德积累 | 自己修上去的 |
| 有没有职司 | 有，必须上班 | 没有，来去自由 |
| 靠什么活 | 香火、供奉、天命 | 自身修为、丹药、洞府灵气 |
| 受谁管 | 天庭、东岳、城隍体系 | 基本没人管，除非犯事 |
| 弱点 | 断香火即衰，革职即贬 | 怕天劫、怕道心破、怕无洞府可归 |

**一句话**：神是公务员，仙是自由职业者。神看不起仙"没编制"，仙看不起神"要看人脸色"。

## 1.2 天庭的品级

1. **帝君 / 四御**：玉皇、紫微、勾陈、后土（后土掌地脉，与地府有旧账）
2. **星君 / 府君**：北斗七星君（注死）、南斗六星君（注生）、东岳大帝（掌生死）
3. **真君 / 天君**：雷部、火部、斗部的实际主官
4. **神将 / 功曹**：执行层，跑腿、缉拿、记录
5. **地方神**：都城隍 → 府城隍 → 县城隍 → 土地 → 家宅六神

**现代比喻**：天庭是中央部委，城隍是市政府，土地是街道办，家宅六神是物业。

## 1.3 职司部门（现代也照这个运转）

- **雷部**：司雷、罚恶、掌天劫。三十六雷将，最忙的是"渡劫监督"。修行者渡劫要报备，不报备的按"野劫"处理。
- **水部**：四海龙王、河伯、水君。行雨有指标，超发要问责，旱涝都要写报告。
- **斗部**：北斗注死、南斗注生。一个人的寿数在出生时就登记，改一次要三级签。
- **瘟部 / 痘部**：司疫病。现代被疾控"代管"，多数时候只负责"签字"。
- **火部**：司火，管城市火灾的"意外率"。
- **财部**：管人间财运。真正的大钱不归它管，它管的是"小财的流向"。
- **城隍体系**：一城之主，管阴阳两界事务；下设判官、黑白无常、牛头马面、夜游神、日游神。
- **东岳大帝**：生死簿的最高上级。判官改簿，要过东岳。
- **家宅六神**：灶君、门神、土地、井神、厕神、床公床母。最基层，也最灵。

## 1.4 仙的层级与路子

**层级**：散仙 → 地仙 → 神仙 → 天仙 → 大罗（传说级，几乎不现世）。
**修行路径**：炼精化气 → 炼气化神 → 炼神还虚 → 还虚合道。
**道门三宗**：正一（符箓，可婚，最接地气）、全真（内丹，出家，最封闭）、上清（阵法，最贵）。
**民间法教**：出马（东北）、傩（西南）、符箓派、扶乩、赶尸、看风水。
**三灾八难**：雷劫、火劫、风劫；心魔劫最难过，多数人死在心魔上。
**现代处境**：多数穷，靠法事、看风水、卖符、看宅过活。真有本事的被九局登记，随时被叫去干活。

## 1.5 请神：能请，但要还

**流程**：请 → 降 → 问 → 送。

- **请**：焚香、报姓名、报事由，不能空口请。
- **降**：请来的未必是你要的那位；越级请，来的可能是"值班的"。
- **问**：一次三问，问完要记下答复，日后对账。
- **送**：必须送，不送会被"留印"，之后麻烦不断。

**代价**：折寿、断子嗣、香火抵押、气运透支、反噬（尤其请了不该请的）。
**规矩**：法不轻传，术不空使。白使一次，反噬翻倍。

# 第二卷 仙界

## 2.1 仙界在哪

**不在天上。** 它是与人间叠着的另一层空间，在天庭辖区内。

- **入口**：昆仑、蓬莱、方丈、瀛洲；三十六洞天、七十二福地；少数名山的"未开放区域"。
- **现代解释**：卫星图上拍不到的地方、景区地图上被抹掉的一块、永远在维修的古道。
- **通行**：云路、仙舟、敕令借道。没有仙籍或敕令，走不进去。

## 2.2 结构

### 云京（天庭治所）
- 行政中心。有衙署、有值房、有档案库、有"考核司"。
- 有派系：旧神派（守规矩、讲香火）、新政派（讲效率、要改革）、边地派（外派多年，回不来）。
- 有贪腐：卖签、压案、改簿、挪香火。

### 洞天福地（散仙的地界）
- 三十六洞天、七十二福地，各有主人。
- 规模差异极大：有的是一座山，有的只是一间石室。
- 规矩：洞天内主人说了算，天庭来人也得通报。

### 海外三岛
蓬莱、方丈、瀛洲。老仙聚集，不问世事，也不服管。

## 2.3 仙界的经济

- **香火**：硬通货，等于"财政拨款"。断香火的神仙会迅速衰落。
- **功德**：信用体系，能换职司、换丹药、换人情。
- **仙丹 / 灵材**：稀缺品，拍卖为主。
- **人情**：最贵的货币。请神三次不还，仙界就没人理你。

## 2.4 仙界的日常

- 有早朝、有值班、有考核（三年一小考，九年一大考）。
- 有文书：奏表、札子、仙牒、敕令。
- 有刑罚：贬职、削籍、打入轮回、锁入镇仙井。
- 有休假：散仙自由，在职神仙要请假（很难批）。

## 2.5 与现代世界的接口

- 九局外事处对接天庭"驻人间办事处"（对外是某宗教团体）。
- 重大项目（水库、地铁、隧道）要"报山神、报河伯"，走的是民俗流程，实际是报备。
- 卫星发射、极地科考，偶尔会"借道"仙界——手续极繁，回报极高。

# 第三卷 冥界

## 3.1 结构与路线

**黄泉路** → **奈何桥** → **酆都鬼城** → **十殿** → **六道轮回台**

- **黄泉路**：入口极多，殡仪馆、老义庄、城隍庙后门、某些老医院的走廊。
- **奈何桥**：分三桥——金桥（有功者）、银桥（常人）、破桥（罪重者）。
- **酆都鬼城**：阴司衙门所在地，也是鬼族的"首都"。有街市、有役所、有黑市。
- **十殿**：审判与刑罚，按罪分殿。
- **轮回台**：六道分流，投胎排号。

## 3.2 行政

| 职 | 职责 | 备注 |
|---|---|---|
| 十殿阎罗 | 分掌审判、刑罚、轮回 | 各有辖区，互相推诿 |
| 判官 | 掌生死簿，可改 | 改簿代价极大，需东岳签 |
| 黑白无常 | 缉拿游魂 | 跑外勤，最累 |
| 牛头马面 | 押解恶鬼 | 武力单位 |
| 孟婆 | 施汤、断前尘 | 唯一不参与审判的 |
| 阴差 / 鬼卒 | 基层执行 | 大量由在册鬼充任 |

## 3.3 生死簿

- **主册**：东岳保管，记生死大数。
- **副册**：判官执掌，记细目（病、灾、意外）。
- **抄本**：城隍庙、阴籍办各存一份，只读。

**改簿**：要三级签（判官—阎罗—东岳）。改寿、改死法、改投胎去向，代价分别是寿元、功德、职司。民间说的"续命"，多半是改了几天的边角料。

## 3.4 刑罚

十八层地狱不是"层"，是十八个职能区：拔舌、剪刀、铁树、孽镜、蒸笼、铜柱、刀山、冰山、油锅、牛坑、石压、舂臼、血池、枉死、磔刑、火山、石磨、刀锯。

现代管理化之后：有刑期、有减刑、有假释（"准其还阳了愿"）、有申诉。判错的案子要赔——赔功德。

## 3.5 轮回

- **六道**：天道、人道、阿修罗道、畜生道、饿鬼道、地狱道。
- **排号**：按功德与业力排序，热门道（人道、天道）要等。
- **孟婆汤**：忘前尘，但忘不干净——记得一点的人，会成为"宿慧者"。
- **例外**：极少数人（有功、有愿、有契）可以"留任"，成为阴差或在册鬼。

## 3.6 与人间的接口

- **阴籍办**：挂在民政局下面，与城隍庙共用一个公章。
- **义庄 / 殡仪馆**：冥界的"口岸"。
- **头七、百日、周年**：不是民俗，是"手续节点"。
- **现代矛盾**：火化率上升导致"魂体不全"；土地紧张导致阴宅涨价；阴籍开始电子化，老鬼不适应。

# 第四卷 鬼族体系

## 4.1 鬼是什么

鬼不是"死人的残影"，是**一族**：有人形、有意识、有社会、有修炼体系，也有户籍。

- **人形为常态**：衣着、口音、习惯随时代更新。看不出体温低，只看得出"这个人不太爱晒太阳"。
- **越强越像人**：弱鬼会露破绽（影子淡、镜子照不清、说话不带气音、狗见了会叫）。
- **本体是"阴形"**：人形只是壳，壳被打散不会死，但会虚弱很久。

## 4.2 层级

| 层级 | 特征 | 对应 |
|---|---|---|
| 游魂 | 无智或半智，只余执念 | 刚死、横死、无祀者 |
| 鬼民 | 有智，可工作、可交易、可婚育 | 大多数在册与在野鬼 |
| 鬼修 | 有法力，能施术、能凝实 | 吞阴/香火/阴德修上来的 |
| 阴帅 / 判官级 | 掌权柄，能号令阴差 | 地府高层 |

## 4.3 两种处境

- **在册鬼**：犯事、欠债或自愿登记，编入地府体系。受罚者在酆都服刑（劳役、抄经、守门、引渡游魂），刑满可投胎或留任阴差。
- **在野鬼**：逃籍、没登记、不想归地府管。混在人群里开店上班送外卖。九局只要守规矩就睁一眼闭一眼。
- 两边互相看不起：在册骂在野"没规矩"，在野骂在册"给地府当狗"。

## 4.4 六条修炼路

| 路线 | 速度 | 代价 |
|---|---|---|
| 吞阴 | 快 | 容易上瘾，吃多会疯 |
| 修香火 | 中 | 庙塌打回原形 |
| 积阴德 | 慢 | 最稳，能修出人味 |
| 借命 | 快 | 重罪，被抓形神俱灭 |
| 结怨 | 快 | 厉鬼路线，极易反噬 |
| 化形 | 极慢 | 能凝实体温影子，甚至生育 |

## 4.5 鬼的生理与禁忌

- **不吃不喝**，靠阴气、情绪残渣、香火活着。
- **怕**：雷、官印、正午的太阳（弱的会伤，强的只是不舒服）、被写进县志（被记录即被锚定）。
- **不能**：还阳、夺阳寿、在普通人面前显阴形、与活人通婚（血脉冲突）。
- **能**：凝实后吃饭、喝酒、生育（极罕见，代价大）、签契、持有产业。

## 4.6 鬼的社会

- **职业**：阴差、引渡人、守墓、殡葬、夜班、代哭、代烧、看风水、做"阴间中介"。
- **经济**：阴钞、纸钱、香火、记忆（可买卖，违法）。
- **律法**：阴律（地府法）与阳律（九局）双重管辖，谁先抓到谁管。
- **政治**：在册派、在野派、野神派（修香火的），三方互相制衡。

## 4.7 鬼与人

普通人看得见鬼，多半以为"那个人气色不好"。城市里到处是鬼：夜班便利店、殡仪馆、老小区、医院走廊。他们也要交房租。

鬼最怕的不是道士，是**举报**——九局一登记，就得搬走。

**鬼市**：每月初一、十五，老城隍庙地下。卖命、卖记忆、卖名字，也卖消息。

# 附：三界关系速查

| 关系 | 状态 |
|---|---|
| 天庭 ↔ 地府 | 名义上下级，实际互相推诿；生死簿是最大摩擦点 |
| 天庭 ↔ 人间 | 通过城隍、土地、行业神对接；大事要报备 |
| 地府 ↔ 人间 | 通过阴籍办、义庄、城隍庙；火化率是最大矛盾 |
| 仙界 ↔ 人间 | 洞天福地不动，人间项目要"借道" |
| 在册鬼 ↔ 在野鬼 | 冷战，偶尔合作 |
| 鬼族 ↔ 妖族 | 互相忌惮，偶有通婚（极罕见） |
| 鬼族 ↔ 九局 | 登记制下的共处，举报是主要手段 |
