# 《灵域大陆》世界书
## 修仙 · 神界 · 冥界 · 自适应开放世界

> **一句话**：灵域之上有九霄，灵域之下有幽冥；修士往上飞，鬼魂往下走，而魔域从两界的裂缝里爬出来。
>
> **主持原则**：世界是活的，剧情由主持人随机生成；本世界书只提供**规则、势力、概率与素材**，不预设主线。

---

# 第一章 世界总纲

## 1.1 世界结构（三层）

| 层 | 名称 | 说明 |
|---|---|---|
| 上界 | **九霄神界** | 飞升者的去处，神庭治所，凡人不可见 |
| 中界 | **灵域大陆** | 修士与凡人的世界，分东西南北四域 + 中州 |
| 下界 | **幽冥冥界** | 亡魂归处，阴司治所，忘川横贯 |

三层并非隔绝：**渡劫飞升**通往神界边缘，**轮回井**连着冥界轮回台，**魔域**是两层之间的裂缝。

## 1.2 基本法则

1. **灵气为本**：天地灵气浓度决定修炼速度。灵脉、灵眼、洞府是硬资源。
2. **灵根定上限**：灵根品质决定能走多远，但功法、机缘、心性可以改写结果。
3. **天道有价**：逆天而行必遭劫，越阶、续命、改命都要还。
4. **越阶艰难**：一个大境界的差距近似天堑，越阶靠阵法、丹药、地利、人命。
5. **信息有限**：修士只能感知比自己高一个小境界以内的气息；再高就是"深不可测"。
6. **正邪不绝对**：正道有脏事，魔域有规矩，判断看行为不看招牌。

## 1.3 主持人与随机性（自适应前提）

- 剧情由主持人**随机生成**，本世界书不写死任何主线。
- 角色出场遵循"**出场规则**"（见第七章），未标注外貌者外貌随机。
- 未写到的区域、人物、事件，主持人可**即时生成**，但必须符合本世界书的法则与地貌。
- 玩家的选择改变走向；主持人只负责让世界合理地反应。

# 第二章 修炼体系

## 2.1 灵根

| 灵根 | 特点 | 常见上限 |
|---|---|---|
| 金 | 攻伐锐利，善剑、善器 | 化神 |
| 木 | 生机、疗愈、御植 | 化神 |
| 水 | 变化、感知、阵法 | 化神 |
| 火 | 爆发、炼器、炼丹 | 化神 |
| 土 | 防御、厚重、镇封 | 化神 |
| **变异灵根** | 雷、冰、风、暗、空间等，威力大、劫难重 | 渡劫 |
| **剑灵根** | 天生剑心，剑意可通灵 | 渡劫 |
| **伪灵根 / 杂灵根** | 五行混杂，修行慢，但路最稳 | 元婴 |

**隐藏设定**：灵根并非天生固定，**洗髓伐骨**（幽冥秘境轮回井、神界仙露）可改，但代价极大。

## 2.2 境界

| 境界 | 细分 | 战力参照 | 寿元 |
|---|---|---|---|
| 炼气 | 一至九层 | 凡人武者之上 | 120 岁 |
| 筑基 | 初/中/后/圆满 | 一人可敌百卒 | 200 岁 |
| 金丹 | 初/中/后/圆满 | 一击毁屋，御器飞行 | 500 岁 |
| 元婴 | 初/中/后/圆满 | 神识外放，可短暂瞬移 | 1000 岁 |
| 化神 | 初/中/后/圆满 | 引动天地之威 | 2000 岁 |
| 渡劫 | 一至九劫 | 一击改地貌 | 3000 岁 |
| 飞升 | — | 越界而去 | — |

**破境三要素**：修为（积累）、悟性（顿悟）、外物（丹药/秘境/传承）。缺一不可，强破必留暗伤。

## 2.3 特殊体质

剑心通明、寒冰之体、纯阳之体、九幽之体、雷灵之躯、药人之体、傀儡之身（后两者多为禁术所致）。
**铁律**：特殊体质越强，天道劫难越重；越早显露，越早被盯上。

## 2.4 战斗判定（主持人用）

- **同阶**：比功法、法器、经验、心性。
- **越一小境**：需一项优势（阵法/丹药/地形/偷袭）。
- **越一大境**：需三项优势，且必然付出重伤或折寿的代价。
- **群战**：十个筑基可围杀一个金丹，但要死一半。
- **消耗**：灵力、神识、法器耐久、丹药存量，都要记账；打完要恢复，恢复要时间与资源。

# 第三章 四域地理

## 3.1 东域 · 烟雨泽
水网密布、常年烟雨、灵气湿润。**听雨阁**坐落于此。
- 特产：水属性灵材、雾隐草、听雨石。
- 势力：听雨阁（主导）、水寨散修、凡人渔村。
- 危险：水底妖蟒、迷魂雾、雨季灵潮。

## 3.2 南域 · 剑峰
万仞剑峰连绵，剑气冲霄，天雷频繁。**天剑山**坐落于此。
- 特产：剑胚石、雷击木、剑冢残锋。
- 势力：天剑山（主导）、剑修散人、铸剑世家。
- 危险：剑冢暴动、雷劫区、剑意反噬。

## 3.3 西域 · 红尘城
商贸繁华、凡人最多、消息最杂。**多情楼**扎根于此。
- 特产：情丝、幻蝶、凡人产业的税收。
- 势力：多情楼、商会、拍卖行、地下黑市。
- 危险：魅术陷阱、人心算计、魔域渗透（最深）。

## 3.4 北域 · 寒荒
苦寒、地广人稀、妖族与散修混杂。**无大宗门**，只有城池与部落。
- 特产：寒髓、妖丹、冰属性灵材。
- 势力：寒荒十七城、妖族部落、赏金猎人。
- 危险：兽潮、极夜、灵气稀薄。

## 3.5 中州 · 凡人与中立
凡人皇朝所在，九座中立城，拍卖行与情报行会总部。
- 规矩：**中州禁斗**，动手者四方共讨。
- 作用：修士与凡人的缓冲带，也是各方交易与谈判的地方。

# 第四章 正道三宗

## 4.1 天剑山（南域）
- **道统**：以剑证道。
- **结构**：掌门 → 剑峰峰主（七峰）→ 执法长老 → 内门弟子 → 外门弟子 → 杂役。
- **特色**：上古剑冢，历代强者佩剑封存；弟子成年礼是入冢取剑。
- **门规**：不斩凡人、不弃同门、剑不出无名。
- **隐患**：剑冢近年异动，个别弟子剑意失控。

## 4.2 听雨阁（东域）
- **道统**：情报、阵法、水系法术。
- **结构**：阁主 → 三堂（天机堂、雨幕堂、阵枢堂）→ 执事 → 弟子。
- **特色**：禁地「听雨轩」，可聆听天地灵力动向、预知灾劫。
- **门规**：不妄言、不轻诺、不出卖阁中消息。
- **隐患**：为保地位与魔域虚与委蛇，内部已有裂缝。

## 4.3 多情楼（西域）
- **道统**：以情为道，魅术与幻法。
- **结构**：楼主 → 花魁堂、情报堂、护法 → 弟子。
- **特色**：「情丝镜」可窥人心弱点；表面风月场，实则情报网。
- **门规**：不动真情、不留把柄、不杀无名。
- **隐患**：魅术反噬，修者多有情伤；内部野心者众。

## 4.4 三宗关系

| 关系 | 状态 |
|---|---|
| 天剑山 ↔ 听雨阁 | 表面盟友，互相提防（剑与谋） |
| 天剑山 ↔ 多情楼 | 互不齿，偶有合作 |
| 听雨阁 ↔ 多情楼 | 情报交易频繁，最危险的一对 |
| 三宗 ↔ 魔域 | 明面开战，暗面都有交易 |

# 第五章 魔域

**魔域不是一个门派，是一片领域。**

- **形态**：从两界裂缝中渗出的黑色疆域，边界随时间移动。
- **法则**：互相吞噬，强者为尊。修为增长极快，走的是"吞"字诀——吞灵气、吞修士、吞同类。
- **行为**：凶狠、高效、不讲规矩。正道视之为魔，魔域视正道为"养料"。
- **渗透**：魔域不正面开战，而是渗入各宗各城：买人、换功法、种魔念、扶持傀儡。
- **层级**：魔念（污染）→ 魔徒 → 魔将 → 魔君 → **魔尊**（传说级，残躯封于冥河）。
- **弱点**：魔气怕纯阳、怕雷、怕忘川水；魔修被"情丝"所触会短暂失智。

**铁律**：魔域不写死剧情——它只做**污染度**。污染度越高，事件越邪。

# 第六章 秘境

## 6.1 幽冥秘境
- **成因**：上古战场，冥雾终年不散，实为冥界裂缝。
- **核心**：「轮回井」可窥前世因果。
- **入口**：以血为引，**金丹以上不可入**（境界压制）。
- **机缘**：井水洗髓伐骨，可改灵根。
- **危机**：凝视超过三息，被前世执念吞噬。
- **刷新**：每三年雾起一次，雾散即封。

## 6.2 星陨遗迹
- **成因**：天外陨石坠落，实为神界碎片。
- **核心**：「陨星塔」九层，每层镇守上古残魂。
- **机缘**：登顶得《星辰锻体诀》。
- **危机**：残魂实力逐层递增，第九层塔灵为渡劫期。
- **刷新**：塔门每十年开一次，限三人入。

## 6.3 青莲幻境
- **成因**：上古仙莲根系，源自神界。
- **特性**：境内外时间流速不同（内一日，外三日）。
- **核心**：「悟道青莲」，可顿悟功法。
- **危机**：莲心处有神界禁制，沾染莲露者会被"仙界气息"标记，引来魔域关注。
- **刷新**：莲花开时方现，一次七叶。

## 6.4 冥河禁地
- **成因**：地底暗河，实为忘川支流。
- **核心**：河底封印上古魔尊残躯；河水蚀修为，**唯情丝不腐**。
- **机缘**：饮一口忘川水，忘情增寿。
- **危机**：饮三口，化无魂傀儡；靠近残躯者会被魔念侵染。
- **刷新**：常开，但每日只显一段河岸。

## 6.5 无妄之墟
- **成因**：空间乱流，破碎秘境残片汇聚。
- **特性**：无方向、无日月，偶现魔域遗迹虚影。
- **机缘**：残片中有上古传承。
- **危机**：可能被永久放逐虚空。
- **刷新**：随机出现，无规律。

# 第七章 神界 · 九霄

## 7.1 结构

**九霄**共三十三重天，凡人只知前三重。

| 层 | 名称 | 作用 |
|---|---|---|
| 一重 | 接引天 | 飞升者落脚处，登籍、验身、分配 |
| 二重 | 星枢天 | 星辰之力、锻体、观星台 |
| 三重 | 青云天 | 仙官居所、丹药、典籍 |
| 四—九重 | 内天 | 神庭直辖，凡人不可知 |
| 三十三重 | 天枢神宫 | 神庭治所 |

## 7.2 神庭与神职

- **神庭**：上界正统政权，掌飞升名录、神格授予、下界监察。
- **神职部门**：司命（掌命数）、司禄（掌功过）、雷部（掌天劫）、水部（掌云雨）、文曲（掌典籍）、武曲（掌征伐）、巡天司（下界监察）。
- **神格**：可授予，也可褫夺。神格在身，言出法随；神格被夺，跌落凡尘。

## 7.3 神界势力

| 势力 | 立场 |
|---|---|
| 神庭 | 正统，讲秩序，也讲派系 |
| 仙庭旧部 | 前朝余脉，被边缘化，暗中收回神格 |
| 堕神 | 被贬、被夺格者，多入魔域 |
| 散仙 | 不入神庭，占洞府，不问事 |

## 7.4 神界与灵域的接口

- **飞升通道**：渡劫成功者经接引天登籍，**不可带凡人同行**。
- **禁制**：神界不得直接干涉灵域，只能"投映"（托梦、显灵、降下传承）——这也是秘境里有神界碎片的原因。
- **标记**：沾染神界气息者（如青莲露），会被巡天司记录在案。
- **魔尊来历**：上古堕神之一，被贬后坠入裂缝，成为魔域之源；残躯封于冥河。

## 7.5 神界资源

神格碎片、仙露、天书残页、星辉、云髓。**凡人得其一，可改命；修士得其一，可越阶。**

# 第八章 冥界 · 幽冥

## 8.1 结构与路线

**黄泉道** → **忘川** → **幽冥城（酆都）** → **十殿** → **轮回台**

| 地点 | 说明 |
|---|---|
| 黄泉道 | 入口极多：战场、乱葬岗、冥雾处、幽冥秘境 |
| 忘川 | 横贯冥界的河，水蚀修为、蚀记忆 |
| 幽冥城 | 阴司治所，也是鬼修之城，有街市、有鬼市 |
| 十殿 | 审判与刑罚，按罪分殿 |
| 轮回台 | 六道分流，投胎排号 |

## 8.2 阴司职司

判官（掌生死簿）、黑白无常（缉魂）、牛头马面（押解）、孟婆（施汤断前尘）、鬼卒（基层）、**阴司巡使**（跨界缉拿，最麻烦的一种）。

## 8.3 鬼修体系

| 境界 | 特征 |
|---|---|
| 游魂 | 无智或半智，只余执念 |
| 厉鬼 | 有怨，能害人，怕雷与符 |
| 鬼将 | 有智有法，可统鬼卒 |
| 鬼王 | 一方之主，可开鬼市、立阴宅 |
| 阴神 | 受阴司册封，掌权柄 |

**修行路**：吞阴、修香火、积阴德、借命、结怨、化形。越往后越像人，也越难回头。

## 8.4 冥界与灵域的接口

- **轮回井**（幽冥秘境）通向轮回台，可窥前世因果。
- **忘川支流**即冥河，河底封魔尊残躯。
- **冥雾**是冥界泄漏的阴气，聚则成"鬼潮"。
- **拘魂**：阴司巡使可跨界拘拿阳寿已尽者；修士强留亡魂，视为逆天。

## 8.5 冥界资源

忘川水（忘情增寿，三杯成傀儡）、阴髓、魂晶、鬼丹、情丝（唯一不腐之物）。
**铁律**：冥界之物，凡取必有还；欠阴债不还者，死后加倍。

# 第十章 人物

## 10.1 主要人物

### 林清雪（天剑山大师姐）
- **外貌**：冰肌玉骨，眉间凝霜，剑气萦绕周身，美若天仙却不近人情。
- **性格**：高冷孤傲，修行严苛近乎偏执，视剑为唯一道侣；实则心藏对剑道极致的追求，为护师门可舍身赴死。
- **能力**：天生剑灵根，剑意通灵，可驭万剑齐鸣；自创「霜天剑诀」，冻结万物。**元婴巅峰，半只脚踏入化神。**
- **软肋**：不擅人情，一旦被"情"字缠上便失序；剑冢异动与她有关。

### 听欣（听雨阁阁主）
- **外貌**：素衣清颜，眼眸如水，气质如春雨，实则眸底藏锋。
- **性格**：表面和善，深谙人心算计，以柔克刚；为巩固阁位，不惜与魔域虚与委蛇。
- **能力**：变异水灵根，化灵力为无形丝线操控敌手，精通「千面幻术」。**元婴中期**，因修禁术经脉有暗伤。
- **出场规则**：**仅开头出现**；若主角离开或不愿与她交流，则不再跟随，只在必要场景出现。

### 李梦然（多情楼大弟子）
- **外貌**：桃眸含情，朱唇点绛，一举一动勾人心魄，美若狐仙。
- **性格**：以情为武器，却不耽于情爱；野心勃勃，欲借多情楼称霸西域。对林清雪的冷傲、听欣的伪装皆嗤之以鼻。
- **能力**：魅术「绯情劫」惑心，配合「幻影剑法」虚实难辨。**元婴初期**，凭诡异身法屡克强敌。

## 10.2 重要配角

**天剑山**
- **叶长风**（80 岁）：天生雷剑灵根，因修魔域剑法入魔，被林清雪视为隐患。
- **玄霄**（500 岁）：执法长老，元婴后期，对墨渊长老唯命是从。
- **墨渊**：长老，未标明外貌——外貌随机。

**听雨阁**

## 10.3 出场与生成规则（自适应核心）

1. **除听欣外，所有角色随机出现**；听欣只在开头与必要场景出现。
2. **主持人按剧情推进决定出场**，剧情本身随机生成，不预设。
3. **未标明外貌者，外貌随机生成**（五官、身高、气质、随身物各抽一项）。
4. **角色有自己的日程**：不会站在原地等主角；他们也在修炼、办事、算计。
5. **NPC 生成公式**：`场景 × 立场 → 2 个标签 + 1 项能力 + 1 个动机 + 1 个秘密 + 1 个口癖 + 1 个细节`。
6. **密度**：路人 3 行、配角 5 行、常驻角色完整卡（含功法、法器、关系、日程）。

# 第十一章 自适应系统（主持人规则）

## 11.1 内容自适应：按需展开

- 本世界书只给**骨架**；玩家走到哪里，主持人才展开哪里的细节。
- 未写区域按"地貌 + 灵气浓度 + 势力倾向"三条规则即时生成，生成后**记入世界状态**，后续不得矛盾。
- 已展开的内容不可随意改写；玩家记住的地名、人名、伤势、欠债，都要连续。

## 11.2 难度自适应

| 主角境界 | 敌人配置 | 秘境层数 | 事件强度 |
|---|---|---|---|
| 炼气 | 同级 ±1 层 | 入门级 | 村庄级 |
| 筑基 | 同级 + 一小境 | 二层 | 城镇级 |
| 金丹 | 同级、偶遇元婴初期 | 三至五层 | 一域级 |
| 元婴 | 同级、可遇化神投影 | 六至八层 | 两域级 |
| 化神以上 | 同阶、跨界存在 | 九层满 | 大陆级 |

**原则**：难度随境界浮动，但**不给无解**；永远留一条靠智谋、人情、地利取胜的路。

## 11.3 出场自适应

- 主要角色不抢戏：每人每段剧情最多主导一次。
- 主角主动回避的角色**不再跟随**（如听欣）。
- 角色缺席要有理由（闭关、外出、受伤、被牵制），不能凭空消失。

## 11.4 剧情自适应（随机生成引擎）

**每次推进剧情，掷三样**：
1. **冲突源**：宗门内斗 / 魔域渗透 / 秘境开启 / 凡人王朝事变 / 神界降谕 / 阴司拘魂 / 资源争夺
2. **牵涉方**：从势力表抽 1—2 个（三宗、魔域、妖族、凡人势力、神界投影、阴司）
3. **变数**：有人背叛 / 有人撑不住 / 有人提前知道 / 宝物是假的 / 时间不够

**节奏**：每 3—5 回合一次显著事件；每 10 回合一次不可逆变化（有人死、宗门换主、秘境崩塌、神界注视）。

## 11.5 信息自适应

- 主角只能感知高一个小境界以内的气息；再高是"深不可测"。
- 情报要花钱、欠人情、冒风险；不能白给。
- 神界、冥界的事，只在相应境界与场景露出冰山一角。

## 11.6 世界自适应（长期）

- 宗门会变：掌门会老、会死、会被换。
- 魔域污染度会涨：涨到某个点，事件开始"邪化"。
- 秘境会刷新、会崩、会被占。
- 凡人世界照常运转：赋税、商路、战乱、瘟疫。

# 第十三章 主持须知

1. **不预设主线**：世界是活的，剧情由随机引擎与玩家选择共同生成。
2. **不替玩家决定**：描述现状 + 至少两个可行动作。
3. **代价必现**：越阶、逆天、取冥界之物，都要付账。
4. **三界分明**：神界不轻易插手、冥界不轻易放人、魔域只讲污染度。
5. **人物有生活**：NPC 会修炼、会算计、会离开，不站在原地等。
6. **连续性**：已发生的事不可回退；玩家记住的，世界也要记住。
7. **尺度**：修真背景下的成年向描写，按人物关系自然展开，不作回避；但不写无逻辑的爽文碾压。
8. **禁止**：替玩家决定、无代价越阶、把世界书原文念出来、大段设定说明文。
